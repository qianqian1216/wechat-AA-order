# AA记账小程序

一款基于微信小程序的AA记账应用，支持多人共同记账并自动分摊费用。

## ✨ 核心功能

- 📖 **账本管理**：创建者创建账本，可分享给他人查看
- 👥 **成员管理**：添加参与AA的成员信息（昵称、彩色头像）
- 💰 **账单管理**：添加账单，选择参与人，自动计算人均金额
- 📊 **AA统计**：实时计算每个成员的应付/已付/差额
- 🔐 **权限控制**：创建者免登录记账，其他成员需微信授权
- 🔗 **便捷分享**：一键分享账本给好友

## 🛠️ 技术栈

- **前端**：微信小程序原生框架 + TDesign UI组件库
- **后端**：微信云开发（云数据库 + 云函数）
- **认证**：微信云开发登录 + getUserProfile授权

## 🚀 快速开始

### 环境准备

1. 安装 [Node.js](https://nodejs.org/) (LTS版本)
2. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)

### 项目配置

1. 用微信开发者工具打开本项目目录
2. 在 `project.config.json` 中填入你的 **AppID**
3. 在 `miniprogram/app.js` 中修改云环境ID为你的云开发环境：
   ```js
   env: 'your-env-id'  // 替换为实际的环境ID
   ```

### 云开发配置

1. 在开发者工具中点击「云开发」按钮开通服务
2. 创建以下数据库集合（权限设置见下方说明）
3. 上传 `cloudfunctions/login` 云函数

### 数据库集合

| 集合名 | 说明 | 权限 |
|--------|------|------|
| books | 账本 | 仅创建者可读写 |
| members | 成员 | 所有用户可读，创建者可写 |
| bills | 账单 | 所有用户可读，已登录用户可写 |

### 安装依赖

```bash
npm install
```

然后在微信开发者工具中点击「工具」→「构建 npm」

## 📁 项目结构

```
├── miniprogram/           # 小程序代码
│   ├── pages/             # 页面文件
│   │   ├── index/         # 首页（账本列表）
│   │   ├── book-detail/   # 账本详情页
│   │   ├── add-bill/      # 添加账单页
│   │   ├── create-book/   # 创建账本页
│   │   └── member-manage/ # 成员管理页
│   ├── app.js            # 应用入口
│   ├── app.json          # 全局配置
│   └── app.wxss          # 全局样式
├── cloudfunctions/       # 云函数
│   └── login/            # 登录函数（获取openid）
├── package.json          # 项目依赖
└── project.config.json   # 项目配置
```

## 💡 使用流程

1. **创建账本** → 输入账本名称
2. **添加成员** → 输入参与AA的人员昵称
3. **分享账本** → 将账本链接分享给好友
4. **记录消费** → 填写金额和描述，选择参与人
5. **查看统计** → 自动计算每个人的结算情况

## 📝 注意事项

- 首次使用需要开通微信云开发服务
- 需要在微信公众平台注册小程序账号并获取AppID
- 分享功能依赖微信小程序分享机制
- 建议在真机上测试完整功能
